# ノイズあり欠陥なしデータセット作成プロジェクト

## 📋 プロジェクト概要

既存の欠陥データに加えて、**ノイズあり欠陥なしデータ**を新規作成し、バランスの取れたデータセットを構築しました。

---

## 🎯 主な変更点

### 1. ノイズあり欠陥なしデータセットの作成

#### データ生成方法
- **ベースデータ**: 応力値を全て0に設定（欠陥なし）
- **ノイズ追加**: Gaussian noise（データ標準偏差の10%）
- **生成数**: 5,000個
- **ラベル**: 全ノードがクラス0（欠陥なし）

#### 技術仕様
- **ノード数**: 13,942ノード/サンプル
- **ラベル形式**: One-hot形式 (13,942, 19)
- **ファイル形式**: `NoiseDefectFree_000001.npy` ~ `NoiseDefectFree_005000.npy`

---

### 2. 新しいデータセット構成

#### データセット内訳
| データタイプ | サンプル数 | 説明 |
|------------|---------|------|
| **ノイズあり欠陥なし** | 5,000個 | 新規作成（ゼロベース + ノイズ） |
| **欠陥あり** | 5,000個 | 既存データからランダム選択 |
| **合計** | **10,000個** | |

#### データ分割
- **Train**: 7,000個 (70%)
- **Val**: 1,500個 (15%)
- **Test**: 1,500個 (15%)

---

### 3. プログラム構成

#### ファイル構成
```
GNN_program/
├── GNN_zscore_sub.py                    # 元のプログラム（変更なし）
├── GNN_zscore_sub_noise_defect_free.py  # 新データセット用プログラム
├── create_noise_defect_free_data.py      # データ生成スクリプト
├── visualize_defect_free_data.py         # 可視化スクリプト
└── run_noise_defect_free.sh              # 実行スクリプト
```

#### 主な機能
- **データ生成**: ゼロベース + Gaussian noise
- **ラベル作成**: 1つのマスターラベルファイルから生成
- **可視化**: データ分布とラベル分布の確認
- **学習実行**: おすすめパラメータでの自動実行

---

### 4. 学習設定（おすすめパラメータ）

#### ハイパーパラメータ
| パラメータ | 値 | 説明 |
|----------|---|------|
| **Loss Function** | LogitAdjustLoss (τ=1.5) | クラス不均衡対策 |
| **Sampler** | Minority Sampler | マイノリティクラス重視 |
| **Learning Rate** | OneCycleLR | 動的学習率調整 |
| **Batch Size** | 64 | |
| **Hidden Channels** | 16 | |
| **Dropout** | 0.1 | |
| **Edge Drop** | 0.01 | |
| **Epochs** | 2000 | |
| **Patience** | 300 | Early stopping |

## 📊 期待される効果

### データセットの改善
- ✅ **クラス不均衡の緩和**: 欠陥なしデータの追加により、クラス0のサンプル数が増加
- ✅ **ノイズ耐性の向上**: 実データに近いノイズを含む欠陥なしデータで学習
- ✅ **汎化性能の向上**: より多様なデータで学習することで、過学習を抑制

### 学習の改善
- ✅ **バランスの取れた学習**: 欠陥あり/なしのバランスが改善
- ✅ **安定した学習**: クラス不均衡対策により、学習が安定化
- ✅ **性能向上**: Macro F1スコアの向上が期待される

## 🚀 使用方法

### 1. データ生成
```bash
python create_noise_defect_free_data.py --noise_std_ratio 0.1 --num_samples 5000
```

### 2. 可視化
```bash
python visualize_defect_free_data.py --num_samples 10
```

### 3. 学習実行
```bash
./run_noise_defect_free.sh
```
