# 欠陥なしデータとの差分計算と可視化

## 差分計算の場所

差分計算は以下のスクリプトで行われています：

**ファイル**: `/home/nishioka/GNN/GNN_hole_2026/subtract_hole_no_defect.py`

**計算箇所**: 70行目
```python
result = data - subtract_data
```

ここで：
- `data`: 元の欠陥データ（各入力ファイルから読み込まれたデータ）
- `subtract_data`: 欠陥なしデータ（`/home/nishioka/GNN/GNN_hole_2026/DSPSS_8x8/hole_no_defect_original.npy`）
- `result`: 差分データ（欠陥データ - 欠陥なしデータ）

## データ処理の流れ

1. **差分計算**: `subtract_hole_no_defect.py`
   - 入力: 複数の欠陥データフォルダ
   - 参照データ: `hole_no_defect_original.npy`
   - 出力: `/home/nishioka/GNN/GNN_hole_2026/all_subtracted_hole_no_defect`

2. **Z-score標準化**: `normalize_all_subtracted_zscore.py`
   - 入力: `all_subtracted_hole_no_defect`
   - 出力: `/home/nishioka/GNN/GNN_hole_2026/all_sub_hole_defect_zscore`

3. **GNN学習**: `GNN_zscore_sub.py`
   - 入力: `all_sub_hole_defect_zscore` フォルダ内のデータ

## 可視化スクリプト

**ファイル**: `/home/nishioka/GNN/GNN_hole_2026/GNN_program/visualize_difference.py`

このスクリプトは、以下の3つのデータを並べて可視化します：

1. **元の欠陥データ** (Original Defect Data)
2. **欠陥なしデータ** (Reference / No Defect Data)
3. **差分データ** (Difference = Original - Reference)

### 使用方法

```bash
cd /home/nishioka/GNN/GNN_hole_2026/GNN_program

# 基本的な使用方法（差分データから元データを再構築）
python visualize_difference.py \
  --difference_dir /home/nishioka/GNN/GNN_hole_2026/all_sub_hole_defect_zscore/test \
  --reference_file /home/nishioka/GNN/GNN_hole_2026/DSPSS_8x8/hole_no_defect_original.npy \
  --output_dir /home/nishioka/GNN/GNN_hole_2026/difference_visualizations \
  --max_files 10

# 元のデータフォルダを指定する場合（より正確な可視化）
python visualize_difference.py \
  --difference_dir /home/nishioka/GNN/GNN_hole_2026/all_sub_hole_defect_zscore/test \
  --reference_file /home/nishioka/GNN/GNN_hole_2026/DSPSS_8x8/hole_no_defect_original.npy \
  --output_dir /home/nishioka/GNN/GNN_hole_2026/difference_visualizations \
  --max_files 10 \
  --original_dirs /home/nishioka/GNN/GNN_hole_2026/DSPSS_8x8/Defect_hole_8x8_original
```

### 出力

可視化結果は以下の形式で保存されます：
- ファイル名: `{データファイル名}_difference_visualization.png`
- 出力ディレクトリ: `--output_dir` で指定したディレクトリ

各画像には、Layer 1（下層）とLayer 2（上層）の両方が含まれ、それぞれに以下が表示されます：
- 元の欠陥データ
- 欠陥なしデータ（参照）
- 差分データ（赤青のカラーマップで表示、赤が正の差分、青が負の差分）

統計情報も画像に含まれます。
