# GNN_HOLE_2026 プロジェクト プレゼン資料 目次

## 1. プロジェクト概要
### 1.1 研究目的
- 欠陥検出における19クラス分類問題への取り組み
- Graph Neural Network (GNN)を用いた空間的パターン認識

### 1.2 問題設定
- 19クラスの欠陥分類タスク
- クラス不均衡問題への対応
- 複数のデータサイズ（2x2, 4x4, 8x8）での検証

---

## 2. データセット
### 2.1 データ構造
- グリッドサイズ: 57列 × 125行
- 2層構造（Layer1, Layer2）
- 穴領域の定義と処理

### 2.2 データ前処理パイプライン
- **引き算処理**: `subtract_hole_no_defect.py`
  - 欠陥なしデータとの差分計算
- **正規化手法の比較**:
  - Z-score標準化
  - Min-Max正規化
  - Robust Z-score標準化
  - Percentile-based outlier removal

### 2.3 データセットバリエーション
- `Defect_hole_2x2_Region1_21_npy`
- `Defect_hole_4x4_Region1_21_npy`
- `Defect_hole_8x8_Region1_21_npy`
- 各データセットの正規化バージョン

---

## 3. モデルアーキテクチャ
### 3.1 Graph Attention Network (GAT)
- **アーキテクチャ概要**:
  - 3層のGATConvレイヤー
  - Multi-head attention (4 heads)
  - Residual connections
  - Batch Normalization
  - Dropout正則化

### 3.2 モデルの特徴
- 入力特徴量: 4次元
- 隠れ層チャネル数: 可変（デフォルト16）
- 出力: 19クラス分類
- Edge dropoutによる正則化

---

## 4. クラス不均衡対策
### 4.1 Loss関数の工夫
- **Focal Loss**: 難易度の高いサンプルに焦点を当てる
- **LogitAdjust Loss**: クラス事前確率を考慮した調整
- **Class-weighted Loss**: クラス重みによる補正

### 4.2 サンプリング戦略
- **Minority Sampler**: 少数クラスのサンプリング強化
- **Hard Example Mining**: 難易度の高いサンプルの重点学習
- **2段階学習 (Stage1/Stage2)**:
  - Stage1: 全体の学習
  - Stage2: Hard exampleに焦点を当てた学習

### 4.3 学習スケジューリング
- OneCycleLRによる学習率スケジューリング
- Stage2開始タイミングの最適化

---

## 5. 学習設定とハイパーパラメータ
### 5.1 分散学習
- Distributed Data Parallel (DDP)
- 4GPU並列学習
- DistributedSamplerによるデータ分散

### 5.2 主要ハイパーパラメータ
- Epochs: 1500
- Batch size: 64
- Learning rate: 0.01
- Hidden channels: 16
- Dropout: 0.1
- Edge dropout: 0.01

### 5.3 データ使用率とサンプリング
- Data usage ratio: 0.5
- Minority weight power: Stage1 (1.5), Stage2 (1.0)
- Hard0 keep ratio: Stage1 (1.0), Stage2 (1.0)
