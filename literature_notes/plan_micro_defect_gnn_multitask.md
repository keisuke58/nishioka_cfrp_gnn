# ミクロ欠陥モデル × 圧倒的Validation × 無限パターンGNN Multi-Task 計画書

> 現状: 欠陥＝単純な物性値の置き換え（マクロ的）
> 目標: ミクロでリアルな欠陥モデル + 圧倒的Validation + 無限パターンをGNN Multi-Taskで予測

---

## 0. 圧倒的に高い目標（North Star）

### ビジョン

**「製造ラインで、未学習の欠陥パターンでも、人間の判断を超える精度でリアルタイムに位置・重症度を推定するシステム」**

### 具体的な目標値（実運用レベル）

| 領域 | 目標 | 実運用での意味 |
|------|------|----------------|
| **検出** | 欠陥見逃し率 < 0.1% | 不良品の流出防止 |
| **位置** | 層・ブロック推定 正解率 > 95% | 修理・廃棄判断の根拠 |
| **重症度** | 連続パラメータ（φ等）誤差 < 5% | 修理優先度・寿命予測 |
| **汎化** | 未学習パターンでも上記を維持 | 新製品・新欠陥への適応 |
| **速度** | 1サンプル < 100ms | ライン速度に追従 |
| **信頼性** | 不確実性付き出力、再現性担保 | 監査・トレーサビリティ |

### 実運用の定義

- **入力**: FEM由来DSPSS（将来はIR等の実測も）
- **出力**: 欠陥有無、位置（層・ブロック）、重症度（連続値）、信頼度
- **環境**: 既存製造フローに組み込み可能なAPI・バッチ処理
- **品質保証**: 検証済みOOD条件での性能保証、ドキュメント整備

## 3. Phase 1: ミクロでリアルな欠陥モデル

### 3.1 現状の「単純な物性値当て」からの脱却

**現状のFEM欠陥モデル（推定）:**
- 欠陥領域の要素に一括で低い弾性係数（E）を設定
- 形状: 矩形（H×W）のみ
- 層・ブロック・要素位置でラベル付け

**ミクロ・リアル化の方向性:**

| 観点 | 現状 | 改善案 |
|------|------|--------|
| **物性の多様性** | 単一のE低下 | 空隙率・脱層・繊維配向乱れ・界面劣化など複数パラメータ |
| **空間分布** | 矩形一様 | ガウシアン減衰・境界ぼかし・不規則形状 |
| **層間効果** | 層ごと独立 | 層間応力伝達・脱層の連成 |
| **物理整合** | 経験的 | マイクロメカニクス（Halpin-Tsai等）に基づく有効物性 |

### 3.2 ミクロ欠陥モデルの具体設計

#### A. 多物性パラメータ化

```
欠陥パラメータ空間（例）:
- φ (空隙率): 0 ~ 0.3
- E_defect / E_base: 0.1 ~ 1.0
- 脱層係数 (層間剛性比): 0 ~ 1
- 形状パラメータ: 楕円率、アスペクト比、境界のぼかし幅
```

→ FEM前処理で、欠陥領域の要素ごとに**位置依存の有効物性**を付与

#### B. マイクロメカニクスベースの有効物性

- **Halpin-Tsai** 等で空隙率φから有効弾性係数を計算
- 脱層は層間せん断剛性の低減としてモデル化
- 境界では**スムーズな遷移**（線形/ガウシアン）で不連続を避ける

#### C. 実装ステップ（FEM側）

1. **FEMスクリプト拡張**: 欠陥領域の要素に `(φ, E_ratio, ...)` を渡すAPI
2. **パラメータサンプリング**: ラテン超立方サンプリング等で多様な欠陥パターン生成
3. **既存パイプラインとの統合**: `subtract_hole_no_defect` → z-score の流れは維持

## 4. Phase 2: 圧倒的Validation設計

### 4.1 現行Validationの拡張

| 分割タイプ | 現状 | 拡張案 |
|------------|------|--------|
| **IID** | ランダム分割 | 維持（ベースライン） |
| **defect_size** | クラス数閾値 | サイズ連続値・面積比・体積比でも分割 |
| **defect_ratio** | 欠陥ノード比率 | 維持 + ビン別評価 |
| **layer** | 層のOOD | 維持 + 層間距離ベースの難易度分析 |
| **（新）物性OOD** | なし | 訓練: 狭いφ/E範囲、テスト: 広い範囲 |
| **（新）形状OOD** | なし | 訓練: 矩形中心、テスト: 不規則形状 |
| **（新）複合欠陥** | なし | 訓練: 単一欠陥、テスト: 複数欠陥 |
| **（新）ノイズレベル** | なし | 訓練: 低ノイズ、テスト: 高ノイズ |

### 4.2 グループ非重複分割の強化

- **LBel (Layer-Block-element)** ベースの group-disjoint を維持
- **物性パラメータ空間**でもグループ化（例: φのビン）
- **交差検証**: 5-fold に加え、OOD fold を明示的に設計

### 4.3 評価指標の拡充

| 指標 | 現状 | 追加 |
|------|------|------|
| 分類 | macro_f1, weighted_f1 | 層別F1、サイズ別F1 |
| 検出 | defect-F1 | AUPRC、Precision-Recall曲線 |
| 位置 | Top-k, 距離誤差 | 重心誤差、IoU（欠陥領域） |
| 不確実性 | なし | 予測エントロピー、信頼区間 |
| 汎化 | OOD macro_f1 | OOD性能の相対低下率 |

## 5. Phase 3: 無限パターンGNN Multi-Task

### 5.1 現状の19クラス固定の限界

- 18層×位置の離散クラス → 組み合わせ爆発で網羅不可
- 新しい欠陥パターンは「未学習クラス」として扱いづらい

### 5.2 無限パターンへのアプローチ

#### 方針A: 回帰ヘッドの追加（連続パラメータ予測）

```
Multi-Task 出力:
├── 検出: 欠陥有無 (2値)
├── 位置: 19クラス（既存・補助）
├── 連続パラメータ: [φ, E_ratio, 重心(x,y,z), サイズ, ...]  ← 新規
└── サイズ: 3クラス（既存）
```

- 連続パラメータを**グラフレベル**または**ノードレベル**で回帰
- 学習時は離散ラベル + 連続真値の両方で監督

#### 方針B: 条件付き生成・埋め込み空間

- 欠陥パターンを**埋め込みベクトル**で表現
- 検出 + 埋め込み回帰 → 類似パターンの検索・クラスタリングが可能に

#### 方針C: メタ学習・Few-shot

- 新規欠陥パターンが少数サンプルで来た場合の適応
- MAML / Prototypical Networks 等の検討

### 5.3 GNN Multi-Task アーキテクチャ拡張

```
                    ┌─────────────────────────────────────────┐
                    │           Shared GAT Backbone            │
                    │   (4→hidden, cross-edge, layer-aware)    │
                    └─────────────────┬───────────────────────┘
                                      │
        ┌─────────────────────────────┼─────────────────────────────┐
        │                             │                             │
        ▼                             ▼                             ▼
┌───────────────┐           ┌───────────────┐           ┌───────────────┐
│ Detection     │           │ Location      │           │ Regression    │
│ (2-class)     │           │ (19-class)    │           │ (φ,E,pos,...) │
└───────────────┘           └───────────────┘           └───────────────┘
        │                             │                             │
        └─────────────────────────────┼─────────────────────────────┘
                                      │
                              ┌───────┴───────┐
                              │ Size (3-class)│  graph-level
                              └───────────────┘
```

**損失設計:**
```
L = λ_det * L_det + λ_loc * L_loc + λ_size * L_size + λ_reg * L_reg
```
- `L_reg`: MSE or Huber for 連続パラメータ
- 重みλは検証性能でチューニング
